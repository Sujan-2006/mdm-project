How to Install via Download QR

                    
    
                        
  • 1Click Generate Download QR button above
    • 
                        
  • 2On any Android phone — open the camera app
    • 
                        
  • 3Point it at the QR code — a link notification appears
    • 
                        
  • 4Tap the link — Chrome opens and APK downloads
    • 
                        
  • 5Tap the downloaded APK — allow unknown sources if prompted — install
    • 
                        
  • 6Open MDM app — enter enrollment token — enroll device ✓
    • 
                    

                


                

                    
How to Enroll via QR

                    
    
                        
  • 1Fill in WiFi credentials and enrollment token above
    • 
                        
  • 2Click Generate QR Code button
    • 
                        
  • 3Factory reset the target Android device
    • 
                        
  • 4On welcome screen — tap the display 6 times quickly
    • 
                        
  • 5Camera opens — scan the QR code shown above
    • 
                        
  • 6Device auto-connects to WiFi, downloads and installs MDM app
    • 
                        
  • 7Device appears in dashboard automatically ✓
    •
